# political-analysis

一个 Claude Skill，用于政治结构分析——用权力、利益、制度、合法性、派系、资源流动、代价反噬和地缘秩序做结构分析，不做道德评判。

适用于分析政治事件、政策、人事变动、清洗整肃、权力斗争、继承安排、意识形态转向、政权稳定性、国家治理、选举联盟、议会政党、利益集团、社会运动、国家能力、财政汲取、战争动员、边疆治理、外交秩序与外部冲突等问题。

## 安装方式

将本 skill 安装到本地 Claude Code 环境中：

```bash
git clone https://github.com/bcyw/political-analysis.git
```

克隆完成后，将 `SKILL.md` 文件放置到你的 Claude Code skills 目录下即可使用。

## 分析框架

主链：题目定标 → 多轮搜索 → 三链成形 → 四线材料 → 竞争解释 → 诊断性证据与反证 → 八维择轴 → 主因果链 → 深文章展开

## 文件说明

- `SKILL.md` — skill 核心定义文件，包含完整的诊断操作链和八维分析框架
